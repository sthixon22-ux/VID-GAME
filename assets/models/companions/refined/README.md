Playable companion derivatives of licensed Quaternius sources. Wolf/fox/horse: authored animal geometry, welded/smoothed contours, original painted materials and native rigs/animations. Griffin: original avian head, feathered wings, lion tail and wing-animation layer around the licensed wolf torso/limb rig. Golem: original stone visor/armor/crystal meshes around the licensed humanoid body, retargeted to the same CC0 motion libraries as the hero. Dragon uses the unchanged native vendor GLB plus runtime material overrides. Exact paths/hashes: DERIVATIVES.json. Source grants/notices: assets/vendor/SOURCES.json. Rebuild: blender --background --factory-startup --python tools/build_companion_art.py. Editable griffin source is under assets/art_sources (ignored by Godot; Blender is not needed to play).
