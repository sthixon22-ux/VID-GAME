# Learned spell and technique effects

Descriptions below are generated from the runtime data. Hover skills in battle for current MP cost, effects and weapon requirements. Class stat boons remain permanent; weapon stat boons apply while equipped. Full class/weapon trees cost 60 shared points, with prerequisites and no level gates. Primary-only mythic rules remain unchanged.

Sundering Roar is a weapon-independent sonic spell. Voice power uses hero level; it does not require an axe. Weapon-contact techniques retain explicit family restrictions. Basic attacks inherit an equipped weapon’s element; explicitly typed techniques use their own type. Defense now has diminishing returns; see [the thematic update](THEMATIC_UPDATE.md).
